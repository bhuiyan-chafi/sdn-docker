# About

This folder contains my personal practice sessions on Kathara. For practice I have chosen the easiest way to bring kathara on my machine.

## Installation

1. Create a python virtual environment
2. Activate it
3. Install kathara in it

```bash
python3 -m venv kathara-env
source kathara-env/bin/activate
pip install kathara
python3 -m kathara --version
```
